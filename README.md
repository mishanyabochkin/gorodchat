# ГородЧат — интернет-версия 0.2

Это статический фронтенд, который можно разместить на GitHub Pages.
Для сообщений используется Supabase Realtime.

## Что нужно сделать один раз

### 1. Создать Supabase проект

Создай бесплатный проект в Supabase.

### 2. Создать таблицу

Открой SQL Editor и выполни файл `supabase.sql` из этого проекта.

### 3. Вставить ключи

Открой `public/config.js` и вставь:

- Project URL
- anon/public key

Именно **anon/public key**, НЕ service_role key.

### 4. Залить на GitHub

Содержимое папки `public` должно находиться в корне GitHub Pages репозитория.

Проще всего:
- создай новый репозиторий;
- скопируй файлы из `public` в корень репозитория;
- включи Settings -> Pages -> Deploy from a branch -> main -> /root.

После этого GitHub даст ссылку вида:

`https://ТВОЙ_НИК.github.io/ИМЯ_РЕПОЗИТОРИЯ/`

### Важно

Это тестовый прототип. Он специально сделан максимально простым:
- без регистрации;
- без телефона;
- без паролей;
- без личных сообщений;
- без районов;
- без модерации;
- сообщения публичны для всех пользователей этого проекта.

Перед открытием для незнакомых людей нужно добавить антиспам, жалобы, модерацию, ограничения запросов и нормальную модель пользователей.

## Почему GitHub Pages + Supabase

GitHub Pages отдаёт HTML/CSS/JS.
Supabase хранит сообщения и передаёт новые сообщения браузерам через Realtime.

Никакого Node.js и ноутбука рядом с телефоном для работы сайта после публикации не требуется.
